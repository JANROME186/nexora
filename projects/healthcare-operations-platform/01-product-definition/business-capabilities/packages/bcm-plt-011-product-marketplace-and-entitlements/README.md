# BCM-PLT-011: Product Marketplace and Entitlements

This capability package defines the HOP product marketplace and entitlement foundation.

It is the editable source model for package publication, commercial offers, license plans, tenant entitlements, installation lifecycle, compatibility, support ownership, telemetry and provider-agnostic billing boundaries.

## Core Rule

A purchased package never grants execution by itself. Runtime consumption must pass entitlement, IAM permission, audit, privacy, tenant scope and regulated clinical controls.

## Package Artifacts

This folder contains the 14 standard Business Capability Package artifacts plus marketplace-specific package artifacts required by the Nexora Product Marketplace Standard.
