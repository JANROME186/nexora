# BCM-IMG-002 — Imaging Reception Capability Package

**Spanish:** Recepción de Imagenología
**Domain:** DOM-06 Imaging
**Priority:** High
**Roadmap:** REL-004
**Bounded Context:** `imaging-operations`
**Primary Aggregate:** `ImagingReceptionIntake` (`AGG-032`)

## Summary
Manages patient check-in at imaging centers, safety screening questionnaires (e.g. MRI safety clearance, renal function / eGFR for contrast), order verification, and radiologist/technician queue routing.
