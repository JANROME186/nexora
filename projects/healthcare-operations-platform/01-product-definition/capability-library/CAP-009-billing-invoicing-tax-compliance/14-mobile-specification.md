# 14 Mobile Specification

## Mobile use cases

- Paciente consulta y descarga factura.
- Paciente captura datos fiscales básicos.
- Médico/empresa consulta documentos asociados cuando tenga permisos.
- Empleado autorizado consulta estado de factura.

## Low-resource support

- Documentos fiscales se descargan bajo demanda.
- No almacenar XML/PDF grandes offline salvo descarga explícita.
- Pantallas ligeras y paginadas.
- IA no es obligatoria para operación fiscal en móvil.
