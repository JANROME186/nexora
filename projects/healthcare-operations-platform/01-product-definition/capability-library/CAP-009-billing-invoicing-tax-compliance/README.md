# CAP-009 Billing, Invoicing & Tax Compliance

**Capability ID:** CAP-009
**Status:** Draft
**Version:** 0.31.0
**Owner:** Product / Finance / Compliance
**Depends on:** CAP-002, CAP-003, CAP-006, CAP-008

Esta capacidad gobierna la facturación, comprobantes fiscales, recibos, notas de crédito, cancelaciones fiscales, impuestos, series/folios y adaptación por país mediante Country Packs.

## Objetivo

Permitir que Nexora emita, administre, cancele y consulte comprobantes de venta de forma trazable, segura, auditable, multi-sucursal, multi-país y desacoplada del proveedor fiscal.

## Alcance MVP

- Configuración fiscal del laboratorio y sucursales.
- Facturación a partir de una venta pagada.
- Emisión de recibo interno cuando no se requiere comprobante fiscal.
- Captura de datos fiscales del paciente o empresa.
- Series y folios por laboratorio/sucursal.
- Estados de factura.
- Cancelación administrativa y fiscal.
- Relación con caja, pagos y órdenes.
- Country Pack inicial para México como referencia conceptual.

## Fuera de alcance MVP

- Contabilidad completa.
- Declaraciones fiscales.
- Nómina.
- Integraciones contables avanzadas.
- Facturación masiva multi-país completamente implementada.
