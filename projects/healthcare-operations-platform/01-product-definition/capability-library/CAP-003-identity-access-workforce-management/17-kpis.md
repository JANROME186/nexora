# 17 KPIs

| KPI | Description |
|---|---|
| User provisioning time | Time from employee creation to active user access. |
| Orphan users | Users not linked to active employees. |
| Excess access findings | Number of access review findings per period. |
| High-risk permission assignments | Count of sensitive permissions assigned. |
| Failed login rate | Authentication failures by tenant and time window. |
| Access review completion rate | Percentage of scheduled reviews completed. |
| Branch access violations blocked | Count of prevented unauthorized branch access attempts. |
| Permission change audit coverage | Percentage of permission changes with complete audit metadata. |
