# User Stories

| ID | Story |
|---|---|
| US-CASH-001 | As a cashier, I want to create a sale from a diagnostic order so that the patient can pay for requested services. |
| US-CASH-002 | As a cashier, I want to receive multiple payment methods so that patients can pay flexibly. |
| US-CASH-003 | As a supervisor, I want to approve discounts above cashier limits so that pricing controls are enforced. |
| US-CASH-004 | As a cashier, I want to print or send a receipt so that the patient has proof of payment. |
| US-CASH-005 | As a branch manager, I want to cancel a sale with authorization so that incorrect transactions can be corrected. |
| US-CASH-006 | As a cashier, I want to process refunds linked to original payments so that refund traceability is preserved. |
| US-CASH-007 | As a cashier, I want to open and close my cash drawer session so that my financial activity is controlled. |
| US-CASH-008 | As a supervisor, I want to review cash differences so that discrepancies are investigated. |
| US-CASH-009 | As an auditor, I want to view a financial audit trail so that every movement can be traced. |
| US-CASH-010 | As an administrator, I want to configure payment methods by branch so that operations adapt to each site. |
