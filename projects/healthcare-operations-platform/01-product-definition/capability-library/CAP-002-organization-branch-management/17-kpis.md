# 17 KPIs

| KPI | Description |
|---|---|
| Branch onboarding time | Time from branch draft creation to activation. |
| Configuration completeness | Percentage of required setup completed per branch. |
| Active branches | Number of active branches by tenant. |
| Service coverage | Number of services enabled per branch. |
| Schedule accuracy | Percentage of appointments created within valid schedule. |
| Configuration change audit coverage | Percentage of configuration changes with audit record. |
| Branch availability errors | Number of rejected operations due to invalid branch configuration. |
