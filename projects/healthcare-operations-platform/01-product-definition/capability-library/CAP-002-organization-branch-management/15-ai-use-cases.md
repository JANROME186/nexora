# 15 AI Use Cases

AI is progressive and optional for this capability.

## MVP Candidate Use Cases

| ID | Use Case | Description | Human Oversight |
|---|---|---|---|
| AI-ORG-001 | Branch setup assistant | Suggest missing configuration for branch activation. | Required |
| AI-ORG-002 | Schedule optimization assistant | Suggest operating hours based on historical demand. | Required |
| AI-ORG-003 | Service availability explanation | Explain why a service is unavailable. | Required |
| AI-ORG-004 | Organization configuration summarizer | Summarize changes before approval. | Required |

## Guardrails

- AI must not activate/deactivate branches without explicit human confirmation.
- AI must not override licensing, compliance or security rules.
- AI suggestions must cite the configuration data used.
