# Commercial Product Modules

This folder stores definition packages for commercial HOP modules after the MVP operational core.

MVP modules continue under:

`06-delivery/mvp/modules/`

Commercial modules are created here only when their definition backlog item starts:

- `COM-MOD-009-patient-and-doctor-portals/`
- `COM-MOD-010-inventory-and-internal-quality/`
- `COM-MOD-011-public-website-and-digital-growth/`
- `COM-MOD-012-platform-hardening-and-saas-operations/`
- `COM-MOD-013-advanced-quality-and-compliance/`
- `COM-MOD-014-imaging-operations/`
- `COM-MOD-015-ai-overlay/`
- `COM-MOD-016-commercial-launch-and-customer-enablement/`

Each module folder must contain the required definition artifacts listed in `../HOP_COMMERCIAL_PRODUCT_BACKLOG.yaml`.
