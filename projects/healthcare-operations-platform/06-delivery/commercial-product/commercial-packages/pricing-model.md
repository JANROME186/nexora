# HOP Initial Pricing Model

## Overview

This document describes the initial pricing model for the Healthcare Operations Platform. All prices are in USD, tax-exclusive, and subject to market validation before commercial launch.

## Subscription Tiers

| Parameter | Starter | Professional | Enterprise |
|-----------|---------|-------------|-----------|
| Base Monthly Price | $499 | $1,499 | Custom Quote |
| Included Users | 5 | 20 | Unlimited |
| Additional User/Month | $29 | $25 | Custom |
| Included Monthly Orders | 2,000 | 10,000 | Unlimited |
| Overage per Order | $0.15 | $0.10 | Custom |
| Included Branches | 1 | 3 | Unlimited |
| Additional Branch/Month | $99 | $149 | Custom |
| Setup Fee | $1,500 | $5,000 | Custom |
| Minimum Contract | 12 months | 12 months | 24 months |
| Onboarding Hours | - | 40 hours | 80 hours |
| Data Migration Package | - | Included | Included |
| Dedicated Account Manager | - | - | Included |
| Custom SLA | - | - | Included |

## Billing Cycles

- **Monthly:** Standard pricing
- **Annual:** 10% discount on base subscription

## Volume Discounts

| Monthly Orders | Discount |
|---------------|----------|
| 25,000+ | 5% |
| 50,000+ | 10% |
| 100,000+ | 15% |

## Add-On Services

| Add-On | Price | Available For |
|--------|-------|--------------|
| Data Migration Service | $2,000 - $10,000 per project | All tiers |
| Custom Integration Development | $3,000 - $15,000 per integration | Professional, Enterprise |
| Extended Training Package | $150/hour | All tiers |
| Premium Support Upgrade | 20% of base subscription/month | Starter, Professional |

## Pilot Program

- **Duration:** 3 months
- **Discount:** 50% off base subscription
- **Exit Criteria:** Onboarding checklist completed, 500+ orders processed, structured feedback provided, zero P1 incidents
