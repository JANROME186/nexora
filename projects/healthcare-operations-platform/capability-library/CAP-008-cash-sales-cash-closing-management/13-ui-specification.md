# UI Specification

## Web/Admin Screens

- Sales Workbench
- Order Payment Screen
- Discount Approval Modal
- Payment Capture Panel
- Receipt Preview
- Sale Cancellation Screen
- Refund Management
- Cash Drawer Session
- Cash Closing Wizard
- Cash Differences Review
- Branch Daily Sales Dashboard

## UX Principles

- Fast keyboard-driven cashier workflow.
- Minimal clicks for payment capture.
- Clear visual state for paid, pending, cancelled and refunded sales.
- Permission-aware action buttons.
- Strong confirmation for irreversible operations.
