- Folio Sequence Configuration
- Tax Configuration List
- Fiscal Provider Configuration

## UX principles

- Formularios simples y progresivos.
- Validación visible antes de emitir.
- Estados claros: borrador, pendiente, emitida, fallida, cancelada.
- Acciones destructivas requieren confirmación y motivo.
- Compatible con navegadores comerciales actuales sin depender de APIs experimentales.
