# CAP-001 Patient Management - KPIs

## Operational KPIs

| KPI | Description |
|---|---|
| Patient registration time | Average time to register a patient. |
| Duplicate warning rate | Percentage of registrations with duplicate candidates. |
| Duplicate confirmation accuracy | Percentage of duplicate warnings confirmed by users. |
| Consent completion rate | Percentage of patients with complete required consent. |
| Patient data completeness | Percentage of required/important fields completed. |

## Quality KPIs

| KPI | Description |
|---|---|
| Patient record correction rate | Frequency of updates shortly after creation. |
| Missing guardian incidents | Minor patient records missing guardian after validation. |
| Privacy access violations | Unauthorized access attempts or policy violations. |
| Audit completeness | Percentage of mutations with complete audit metadata. |

## Experience KPIs

| KPI | Description |
|---|---|
| Patient portal profile completion | Percentage of portal users completing profile. |
| Registration abandonment rate | Abandoned patient creation attempts. |
| Mobile low-resource error rate | Errors on low-resource devices. |
