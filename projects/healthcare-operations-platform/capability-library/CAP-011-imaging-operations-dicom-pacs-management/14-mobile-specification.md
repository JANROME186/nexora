# Mobile Specification

## Patient App

- View imaging appointment details.
- Receive preparation instructions.
- Access released report.
- Open lightweight image viewer link when supported.
- Share secure access link with physician when allowed.

## Physician App

- View imaging reports for referred patients.
- Access lightweight viewer links.
- Receive critical finding notifications.

## Staff App

- Technician worklist.
- Patient check-in confirmation.
- Acquisition completion confirmation.
- Issue reporting.

## Progressive Mobile Strategy

- Low-end devices must support appointment details, report PDF viewing and basic image link access.
- Advanced image manipulation is not required on low-end devices.
- Offline behavior should allow viewing cached appointment metadata but not cached clinical images unless explicitly permitted by policy.
