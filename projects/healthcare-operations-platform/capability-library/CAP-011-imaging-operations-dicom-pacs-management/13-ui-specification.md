# Web UI Specification

## Admin Portal Screens

- Imaging dashboard.
- Imaging appointment calendar.
- Imaging room/modality management.
- Technician worklist.
- Radiologist worklist.
- DICOM reconciliation queue.
- Imaging report editor.
- Report signature and release screen.
- Viewer access audit screen.

## UX Principles

- The imaging workflow must be simple enough for branch users with minimal training.
- Advanced PACS/viewer tools must be progressive and feature-flagged.
- Scheduling must clearly show preparation, duration and unavailable resources.
- DICOM reconciliation must prevent accidental patient mismatches.
- Reports must clearly show draft, signed, released and amended status.

## Browser Compatibility

- Core scheduling, worklists and report access must work on current commercial browsers.
- Advanced image viewing may require enhanced browser capability and must show a fallback message when unsupported.
