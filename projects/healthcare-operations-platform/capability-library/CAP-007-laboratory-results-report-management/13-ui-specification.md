# Web UI Specification

## Screens
- Result Worklist
- Result Entry
- Result Review
- Critical Alerts
- Validation Queue
- Report Preview
- Report Delivery Audit
- Result Version History

## UX Principles
- Prioritize clear status indicators.
- Avoid heavy UI that affects low-resource browsers.
- Use progressive enhancement for AI summaries and advanced charts.
- Never hide critical alerts behind optional UI features.
