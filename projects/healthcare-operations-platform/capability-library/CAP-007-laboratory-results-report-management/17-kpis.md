# KPIs

| KPI | Description |
|---|---|
| Turnaround Time | Time from sample acceptance to result release. |
| Validation Time | Time from result entry/import to clinical validation. |
| Critical Alert Response Time | Time from critical detection to acknowledgment. |
| Amendment Rate | Percentage of released reports amended. |
| Delivery Success Rate | Percentage of reports successfully delivered. |
| Manual Entry Rate | Percentage of results entered manually vs imported. |
