# Data Migration & Portability

Nexora incorpora la migración de datos como capacidad transversal. El objetivo es permitir que un laboratorio migre desde otra plataforma con formatos simples, abiertos y exigibles a cualquier proveedor.

## Principios

- Data Portability First.
- Sin vendor lock-in.
- Formatos abiertos y comunes.
- Importación con prevalidación y aprobación humana.
- Idempotencia y reconciliación.
- Exportación completa del cliente.

## Formatos mínimos esperados

- CSV UTF-8
- XLSX
- JSON / NDJSON
- XML
- SQL dumps comunes
- HL7 / FHIR / ASTM cuando aplique
- DICOM / DICOMDIR para imagenología
- PDF / JPG / PNG / TIFF para documentos
