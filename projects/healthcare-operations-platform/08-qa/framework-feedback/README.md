# HOP Framework Feedback

This folder stores Healthcare Operations Platform execution feedback that may improve the Nexora framework.

Agents should create feedback here when HOP analysis, backlog implementation, validation, module closeout or
release readiness reveals reusable framework ambiguity, missing templates, missing prompts, repetitive work,
validation gaps or automation opportunities.

Project-local index:

```text
framework-feedback-index.md
```

Reusable improvements may be proposed to:

```text
../../../../nexora-framework/07-governance/framework-improvement-backlog/
```

Agents must not implement framework improvements unless Nexora explicitly assigns the central backlog item.
