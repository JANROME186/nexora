# Security Quality Evidence

This folder stores backlog-level evidence for the Nexora Open Source First Security and Quality Standard.

Each code-changing backlog item must create:

```text
08-qa/security-quality/<backlog-item-id>/security-quality-evidence.yaml
08-qa/security-quality/<backlog-item-id>/security-quality-evidence.md
```

Evidence must cover applicable open source checks for tests, SAST/static analysis, dependency vulnerabilities, secrets, coverage and DAST when a runnable web/API surface exists.
