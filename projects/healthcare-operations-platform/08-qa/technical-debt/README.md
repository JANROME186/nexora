# HOP Technical Debt

This folder tracks non-blocking modernization, migration, dependency, framework and tooling debt
found during Healthcare Operations Platform backlog execution.

Agents must review technology debt during every code-changing backlog item, module closeout and
release readiness gate. The initial stack is the current baseline, not a permanent constraint.

When a better open source, safer, more maintainable or more cost-effective option is detected but is
not required to complete the active backlog safely, register or update a debt item here and plan
gradual remediation when the affected component is touched.
