# Validators

Los validadores garantizan que el conocimiento de Nexora sea consistente antes de generar artefactos o permitir que un agente lo consuma.

## Validadores iniciales

- Specification Linter.
- Metadata Validator.
- Deprecated Concept Validator.
- Source of Truth Validator.
- Domain Ownership Validator.
- Knowledge Traceability Validator.
- Migration Model Validator.
