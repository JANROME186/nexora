## Key Architectural Principles

1. **Agent-Agnostic**: Zero proprietary AI agent or vendor dependencies. All steps are executable by human engineers or standard open-source tools.
2. **Open-Source-First**: Stack relies exclusively on open source technologies (Spring Boot, React, PostgreSQL, Docker, Vitest, JUnit).
3. **Traceability**: All customer configurations map directly to Business Capability Packages (`BCM-ORG-001`, `BCM-ORG-002`, `BCM-ORG-003`, `BCM-PLT-001`, `BCM-PLT-002`, `BCM-PLT-006`, `BCM-PLT-007`, `BCM-PLT-008`, `BCM-PLT-010`).
