# File Exchange Strategy

**Artifact ID:** IIA-FILE-001  
**Version:** 0.20.0  

## Purpose

File exchange supports batch integrations with external systems and laboratories that cannot consume modern APIs.

## Supported Formats

- CSV.
- XML.
- JSON.
- PDF.
- ZIP packages.

## Supported Transports

- SFTP.
- Secure object storage bucket.
- Manual upload.
- Scheduled import folder in on-premise deployments.

## Controls

- File checksum.
- Virus/malware scanning when available.
- Schema validation.
- Import preview.
- Reconciliation report.
- Error report.
- Audit log.
