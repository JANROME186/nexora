# UI-001 Patient Registration Web Screen

The screen must prioritize simplicity, accessibility and compatibility with common browsers while supporting progressive enhancement.

## Core experience

- Basic patient data form.
- Required field validation.
- Guardian section when applicable.
- Clear errors.
- Save/cancel actions.

## Enhanced experience

- Duplicate detection hints.
- Autocomplete for catalogs.
- Inline validation.

## Intelligent experience

- AI-assisted data cleanup.
- Suggestions for duplicate candidates.
