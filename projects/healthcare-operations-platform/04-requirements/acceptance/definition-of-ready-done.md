# Definition of Ready / Definition of Done

## Definition of Ready for Development

A capability is ready for development when:

- It exists in BCM-001.
- It has a capability requirements file.
- It has functional requirements.
- It has user stories.
- It has acceptance criteria.
- It identifies actors and portals.
- It identifies related aggregates and events.
- It identifies security and audit expectations.
- It has traceability in RTM-001.

## Definition of Done for Implementation

A capability is done when:

- OpenAPI contracts exist and are validated.
- Backend use cases are implemented.
- Frontend/mobile interactions are implemented when applicable.
- Tests exist and pass.
- Security and permission rules are enforced.
- Audit events are recorded.
- Observability is implemented.
- Documentation is updated.
- Generated artifacts are refreshed.
