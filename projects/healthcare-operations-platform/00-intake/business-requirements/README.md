# Business Requirements

This folder tracks business requirement versions and change impact assessments.

The current active business requirement remains at the project root:

```text
../../BUSINESS_REQUIREMENT.md
```

The version index is:

```text
BUSINESS_REQUIREMENT_INDEX.yaml
```

Agents must resolve the latest business requirement version through the index before analysis, validation, planning or development.

When the business updates the requirement, the agent must generate an impact assessment before updating derived artifacts or implementation scope.
