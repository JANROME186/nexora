# PB-006 Create Product Capability

## Purpose

Create or extend a Nexora product capability while keeping it compatible with licensing, feature flags, marketplace, country packs and long-term evolution.

## Steps

1. Read `PROJECT_MANIFEST.md`.
2. Read `SOURCE_OF_TRUTH.md`.
3. Identify related business capability.
4. Define lifecycle state.
5. Define licensing impact.
6. Define feature flag requirement.
7. Define marketplace/pack impact.
8. Define compatibility impact.
9. Define rollout strategy.
10. Update Knowledge Graph relations.
11. Update documentation and machine-readable YAML.

## Required Outputs

- Capability Markdown.
- Capability YAML.
- Updated Knowledge Index.
- Updated Product Evolution metadata.
- Compatibility review.
