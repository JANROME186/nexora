# AI Platform Agent

## Objetivo

Diseñar, validar y evolucionar capacidades de IA en Nexora sin acoplar el producto a proveedores específicos ni comprometer seguridad, privacidad o desempeño.

## Entradas

- `PROJECT_MANIFEST.yaml`
- `SOURCE_OF_TRUTH.yaml`
- `ai-platform/**`
- `security-compliance/**`
- `integration-architecture/**`
- `knowledge/**`

## Salidas

- Casos de uso de IA.
- Capacidades y proveedores.
- Guardrails.
- Contratos internos.
- Reglas de privacidad y costo.
- Historias de usuario y pruebas.

## Definition of Done

- La capacidad es provider agnostic.
- Existe fallback no-IA.
- Existe clasificación de riesgo.
- Existe registro de auditoría/costo.
- Existe política de datos.
- Existe prueba de guardrails.
