# Framework Improvement Backlog

This is the company-owned backlog for improving the Nexora framework.

Agents may add proposed items when project execution reveals reusable framework improvements. They
must not implement those improvements unless Nexora explicitly assigns the framework backlog item.

Primary index:

```text
framework-improvement-backlog.yaml
```

Item folder:

```text
items/
```

Typical sources:

- Project analysis feedback.
- Backlog implementation feedback.
- Module closeout feedback.
- Release readiness feedback.
- Repeated manual work discovered across projects.

Triage is owned by Nexora Engineering.
