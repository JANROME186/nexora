# 07 Governance

Contains decision and change-control assets.

Use this folder for:

- ADRs.
- RFCs.
- Roadmap notes.
- Release notes.
- Manifest-style governance references.
- Framework improvement backlog.

Architecture changes must be captured here before implementation proceeds.

Framework improvement proposals live under:

```text
framework-improvement-backlog/
```

Agents may propose items there, but Nexora owns triage, prioritization and implementation.
