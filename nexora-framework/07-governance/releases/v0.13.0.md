# Release v0.13.0

## Objective

Introduce the Product Knowledge Graph foundation for Nexora.

## Generated artifacts

- Knowledge graph principles.
- Node ID convention.
- Node schema.
- Relation schema.
- Patient Management nodes.
- Patient Management index.
- Patient Management relations.
- Change impact analysis playbook.
- AI Context Builder profile.

## Impact

This release changes the repository from a documentation repository into the initial version of a traceable Engineering Knowledge Platform.

## Next iteration

Create Business Architecture v1 for the Patient Journey, including value stream, BPMN-style process documentation, event storming and business rules.
