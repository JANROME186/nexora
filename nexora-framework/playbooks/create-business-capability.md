# Playbook: Create Business Capability

## Objective

Create a complete Nexora Capability Library package for a business capability.

## Steps

1. Read `PROJECT_MANIFEST.yaml`.
2. Read `SOURCE_OF_TRUTH.yaml`.
3. Assign capability ID using the Knowledge ID convention.
4. Create folder under `capability-library/{CAP-ID}-{slug}`.
5. Create `README.md` and `capability.yaml`.
6. Define capability purpose, actors, goals, included and excluded scope.
7. Define business rules before user stories.
8. Define decision tables for conditional behavior.
9. Define state machines for lifecycle entities.
10. Define BPMN/process flows.
11. Define Event Storming model.
12. Define DDD model.
13. Define entities and value objects.
14. Define domain events.
15. Define commands and queries.
16. Define user stories and acceptance criteria.
17. Define OpenAPI contract scope.
18. Define UI and mobile requirements.
19. Define AI use cases and guardrails.
20. Define QA specification.
21. Define KPIs and compliance controls.
22. Update Knowledge Graph.
23. Run validation pipeline.

## Definition of Done

- Capability has Markdown and YAML artifacts.
- Rules are traceable to stories and tests.
- OpenAPI scope exists.
- Entities and events are listed.
- UI and mobile specs exist.
- Compliance and KPI sections exist.
- Knowledge node exists.
