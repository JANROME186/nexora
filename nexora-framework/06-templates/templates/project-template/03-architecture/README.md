# 03 Architecture

Place application, technology, data, security, integration and AI architecture here.

Required technology governance artifacts:

- `client-stack-market-validation.md` - validates requester-proposed and current stack against current stable or LTS open source market practice.
- `stack-quality-toolchain-baseline.md` - defines the applicable open source quality, security, vulnerability, coverage, SBOM and modernization tooling for the selected stack.
- `local-toolchain-inventory.md` - records local executable paths, versions and generic commands for the selected stack on the current development machine.
