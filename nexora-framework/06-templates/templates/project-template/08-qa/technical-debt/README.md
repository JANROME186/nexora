# Technical Debt

This folder tracks non-blocking technology debt discovered during backlog execution, module closeout
and release readiness reviews.

Use this register when quality, vulnerability, dependency, framework or technology reviews identify
that a component should eventually be upgraded, migrated or reworked, but the change is not required
to safely complete the current backlog item.

Agents must prefer gradual remediation when future backlog work touches the affected components.
Critical or high-risk findings may be promoted to blocking work.
