# Framework Feedback

This folder stores project execution feedback that may improve the Nexora framework.

Agents create feedback here when analysis, validation, backlog implementation, module closeout or
release readiness reveals framework ambiguity, missing templates, missing prompts, repetitive work,
validation gaps or automation opportunities.

Project-local index:

```text
framework-feedback-index.md
```

Framework feedback is not project technical debt. Project technical debt remains under:

```text
08-qa/technical-debt/
```

Agents may propose central framework backlog items, but Nexora owns prioritization and
implementation.
