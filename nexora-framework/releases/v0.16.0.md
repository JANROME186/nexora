# Release v0.16.0 - Enterprise Data & Information Architecture

## Objetivo de la iteración

Incorporar la arquitectura empresarial de datos de Nexora para que la plataforma no solo tenga entidades y tablas, sino un modelo claro de información, gobierno, clasificación, ciclo de vida, propiedad y trazabilidad.

## Decisiones principales

- La información clínica, administrativa, financiera y operativa será tratada como activo empresarial.
- Cada dato relevante deberá clasificarse por tipo, sensibilidad, propietario, origen, ciclo de vida y retención.
- El modelo de datos físico nunca será la fuente primaria del negocio; derivará de dominios, capacidades, procesos y metamodelo.
- Los datos maestros se gobernarán de forma centralizada para evitar duplicidad e inconsistencias.

Esta versión prepara la base para construir el modelo ER empresarial, las migraciones, las políticas de auditoría, la estrategia multi-tenant, el gobierno de datos y las reglas de privacidad de forma consistente.
