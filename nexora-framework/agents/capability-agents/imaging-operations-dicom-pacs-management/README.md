# Imaging Operations Capability Agent

## Mission

Create, validate and evolve CAP-011 artifacts without breaking patient/order/result/security/data traceability.

## Required Inputs

- CAP-011 capability package.
- Orders, Patients, Doctors, Results and IAM capabilities.
- Imaging OpenAPI contract.
- Integration architecture for DICOM/PACS.
- Security and compliance architecture.

## Required Outputs

- Updated capability artifacts.
- OpenAPI contract changes.
- Knowledge graph nodes and relations.
- QA and security test updates.
