# New Nexora Project Template

Copy this folder structure to:

`projects/<project-slug>/`

Before running an agent, the requester must provide `BUSINESS_REQUIREMENT.md` in the project root.

After that, run the Nexora Project Analysis and MVP Workflow followed by the Nexora Agent-to-MVP Recipe. The agent will structure the requester-supplied requirement into `PROJECT_BRIEF.md` for people and `PROJECT_BRIEF.yaml` for agent execution.
