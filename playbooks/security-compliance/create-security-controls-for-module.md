# Playbook: Create Security Controls for Module

## Steps

1. Load project manifest.
2. Load module capability definition.
3. Load business rules and data classification.
4. Identify protected actions.
5. Create permission keys using the official convention.
6. Identify audit events.
7. Identify privacy constraints.
8. Update OpenAPI security requirements.
9. Add security acceptance criteria to stories.
10. Update Knowledge Graph relationships.
11. Validate against Security and Compliance Baseline.

## Output

- Permission list.
- Audit event list.
- Security acceptance criteria.
- OpenAPI security annotations.
- Knowledge relationships.
