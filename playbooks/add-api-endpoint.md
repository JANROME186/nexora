# Playbook: Agregar endpoint API

## Objetivo

Agregar un endpoint respetando API Contract First.

## Pasos

1. Identificar capacidad y dominio relacionados.
2. Validar historia de usuario y regla de negocio.
3. Actualizar contrato OpenAPI en `contracts/openapi/`.
4. Versionar cambios si son breaking changes.
5. Actualizar Knowledge Index con endpoint.
6. Actualizar casos de prueba contractuales.
7. Documentar impacto.
