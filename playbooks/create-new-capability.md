# Playbook: Crear nueva Business Capability

## Objetivo

Crear una capacidad de negocio trazable desde proceso hasta implementación.

## Pasos

1. Leer `CONSTITUTION.md`.
2. Leer `SOURCE_OF_TRUTH.yaml`.
3. Crear carpeta en `business/capabilities/<capability-name>/`.
4. Crear README de capacidad.
5. Definir objetivos, usuarios, procesos y reglas.
6. Crear nodos en `KNOWLEDGE_INDEX.yaml`.
7. Relacionar dominios DDD, historias, APIs y entidades.
8. Actualizar `PROJECT_STATE.yaml`.
9. Actualizar `CHANGELOG.md`.
