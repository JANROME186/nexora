# HRP-001 — Healthcare Reference Processes

## Purpose

HRP-001 defines the reference operational processes required to implement the MVP of the Healthcare Operations Platform.

These are not UI flows. They are business process baselines that agents must use when generating APIs, domain events, application services, tests and portal screens.

## MVP Processes

| Process | Name | Module |
| --- | --- | --- |
| HRP-001-P01 | Tenant and Branch Setup | MVP-MOD-001 |
| HRP-001-P02 | Diagnostic Catalog Publication | MVP-MOD-002 |
| HRP-001-P03 | Patient Registration and Order Intake | MVP-MOD-003 / MVP-MOD-004 |
| HRP-001-P04 | Payment and Billing Request | MVP-MOD-005 |
| HRP-001-P05 | Sample Collection and Processing | MVP-MOD-006 |
| HRP-001-P06 | Result Validation and Release | MVP-MOD-006 |
| HRP-001-P07 | Result Report and Digital Delivery | MVP-MOD-007 |
| HRP-001-P08 | Migration and Integration Dry Run | MVP-MOD-008 |

## Implementation Rule

Every MVP implementation story must map to at least one HRP process step or explicitly state that it is platform infrastructure.
