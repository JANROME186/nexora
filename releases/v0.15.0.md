# Release v0.15.0

## Objective

Introduce the Nexora Meta Model baseline and convert Patient Management into the first dual-format, traceable capability.

## Added

- Meta Model directory.
- Artifact type catalog.
- JSON schemas for main artifact types.
- Patient Management dual-format artifacts.
- Traceability record for Patient Management.
- Meta Model Agent.
- Playbook for dual-format artifacts.
- ADR-004 and RFC-001.

## Impact

This release changes Nexora from a document repository into the beginning of a computable product model.

Future agents should prefer YAML artifacts for deterministic context loading and Markdown artifacts for human review.
