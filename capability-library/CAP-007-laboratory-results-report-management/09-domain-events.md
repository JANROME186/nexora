# Domain Events

| Event ID | Event Name | Trigger |
|---|---|---|
| EV-RES-001 | ResultReceivedFromAnalyzer | Analyzer result imported. |
| EV-RES-002 | ResultEnteredManually | User saves manual result. |
| EV-RES-003 | CriticalValueDetected | Result matches configured critical threshold. |
| EV-RES-004 | ResultTechnicallyValidated | Authorized user performs technical validation. |
| EV-RES-005 | ResultClinicallyValidated | Authorized professional performs clinical validation. |
| EV-RES-006 | ResultReportGenerated | PDF/structured report generated. |
| EV-RES-007 | ResultReportSigned | Report signed digitally or electronically. |
| EV-RES-008 | ResultReleased | Result becomes available for delivery. |
| EV-RES-009 | ResultDelivered | Report delivered through a channel. |
| EV-RES-010 | ResultAmended | Released result corrected with new version. |
