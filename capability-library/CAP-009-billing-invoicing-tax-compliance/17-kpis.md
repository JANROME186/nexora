# 17 KPIs

| KPI | Description |
|---|---|
| Invoice issue success rate | Porcentaje de facturas emitidas exitosamente. |
| Average issue time | Tiempo promedio de emisión fiscal. |
| Provider failure rate | Porcentaje de errores por proveedor fiscal. |
| Cancellation rate | Porcentaje de facturas canceladas. |
| Retry success rate | Éxito de reintentos después de fallas. |
| Missing fiscal data rate | Solicitudes detenidas por datos incompletos. |
| Duplicate prevention count | Intentos duplicados bloqueados. |
