# 13 UI Specification

## Admin Portal

Pantallas MVP:

- Listado de médicos.
- Alta/edición de médico.
- Perfil médico.
- Asignación de sucursales.
- Especialidades y credenciales.
- Historial de auditoría.
- Invitación al portal médico.

## Portal Médico

- Dashboard médico.
- Órdenes relacionadas.
- Resultados disponibles.
- Descarga de PDF.
- Perfil y preferencias.

## UX

Debe ser simple, compatible con navegadores comerciales comunes y con experiencia progresiva. Funciones de IA deben aparecer como mejoras opcionales, no como requisito para operar.
