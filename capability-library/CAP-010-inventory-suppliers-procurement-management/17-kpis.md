# KPIs

| KPI | Description |
|---|---|
| Stockout Rate | Percentage of items unavailable when required. |
| Expired Stock Value | Monetary value of expired supplies. |
| Inventory Accuracy | Difference between system and physical stock. |
| Purchase Cycle Time | Time from request to receipt. |
| Supplier Lead Time | Average time per supplier delivery. |
| Reorder Alert Resolution Time | Time to resolve low stock alert. |
| Consumption Cost per Test | Estimated cost of supplies by test. |
| Adjustment Rate | Number of adjustments per period. |
