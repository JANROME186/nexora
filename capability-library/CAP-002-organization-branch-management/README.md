# CAP-002 Organization & Branch Management

**Capability ID:** CAP-002  
**Name:** Organization & Branch Management  
**Status:** Draft  
**Specification Version:** 0.24.0

This capability defines how Nexora manages laboratories, companies, branches, operational units, hierarchy, addresses, schedules, service availability and multi-tenant organizational boundaries.

It is foundational for identity, permissions, orders, inventory, caja, billing, reporting and SaaS licensing.
