# 13 UI Specification

## Web Areas

### Admin Portal

Screens:

- Organization setup wizard.
- Tenant profile.
- Branch list.
- Branch detail.
- Branch schedule editor.
- Branch services configuration.
- Organizational structure view.
- Position hierarchy editor.

## UX Principles

- Simple forms with progressive disclosure.
- Wizard flow for initial onboarding.
- Branch status clearly visible.
- Warnings before operationally risky changes.
- Responsive layout for desktop and tablet.
- Compatible with commercial browsers.
- Avoid heavy UI interactions that degrade low-resource devices.
