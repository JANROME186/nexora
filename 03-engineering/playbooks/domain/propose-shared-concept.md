# Playbook — Propose Shared Kernel Concept

## Steps

1. Identify duplicated concept.
2. List all bounded contexts using it.
3. Confirm it is stable and context-neutral.
4. Define fields and validation rules.
5. Check country-pack dependency.
6. Check backward compatibility.
7. Update `shared-kernel.yaml`.
8. Run Shared Kernel Validator.
9. Update generated documentation.
10. Record architecture review outcome.
